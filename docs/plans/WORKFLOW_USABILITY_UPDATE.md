# VoiceDesign、图书工作台与模型状态改进

日期：2026-10-16。已安装并完成本机 CUDA 实际验证。

## 交付内容

1. **声音与引擎兼容性。** VoiceDesign 根据文字描述设计声音，不能直接使用音频克隆档案。生成页保留引擎选择，发现不兼容时在提交前解释原因并禁用提交，提供“通过描述创建设计声音”入口，直接打开正确的创建模式。现有克隆档案不转换、不覆盖。图书页面使用同一套兼容性规则，并支持 VoiceDesign。
2. **图书生成状态。** 章节状态接口附带真实任务进度，工作台复用生成页的阶段/已耗时/剩余时间组件，展示排队、模型载入、声音准备、语音生成和保存。第一次没有足够样本时明确显示“正在估算”，超出预估时说明，不伪造倒计时。单句徽标显示对应阶段，总进度继续按已处理句数统计。
3. **模型内存管理。** 在模型详情、生成框展开区域和图书设置抽屉提供载入/切换/卸载控件。显示实际内存载入状态、操作耗时与错误，区分已下载和已载入；卸载保留下载文件。明确请求切换时先卸载其他已载入的 TTS 模型。语音推理、图书批次、预热和模型变更互斥，图书句间等待也不会被误判为空闲；忙碌请求返回 409 和解释。取消推理或模型载入时等待后台线程退出，避免后续卸载与 CUDA 工作重叠。Qwen Base 失败载入后清理不完整实例；VoiceDesign 已缓存加载走本地离线路径。
4. **两栏图书工作台。** 按用户选择，左侧放图书切换和章节目录，右侧保留正文与批量操作。声音和模型设置统一放右侧抽屉，不再常驻第三栏。顶部显示下次使用的声音/模型；进入工作台继承兼容的当前选择。语音版本默认折叠，技术文件路径不挤占正文，已有编辑、排序、版本选择、回收站、试听和导出功能保留。进入图书时结束其他页面的试听，避免旧播放器遮挡正文或叠加播放，后台生成继续。

## 实际验证

环境：Windows、RTX 5070 Ti、安装版 CUDA 后端；使用已完整下载的模型，没有重复下载。

- 从不兼容的克隆档案选择 VoiceDesign，实际界面在提交前显示解释和创建入口；入口直接打开“描述声音”模式。
- 创建独立中文档案“VoiceDesign 验收声音”，类型为 `designed`，默认引擎 `qwen_voice_design`。原有声音档案保持不变。
- 创建独立“工作流验收”图书，三句均由 VoiceDesign 生成成功。输出时长分别约 5.66、4.06、22.32 秒，WAV 均可读取。
- 观察记录包含 `loading_model`、`preparing_voice`、`generating`、`finalizing`，也观察到可用的 `estimated_remaining_seconds`。窗口里的阶段和已耗时正常更新。记录采集耗时含提交前等待，不作为性能基准。
- 真正推理期间请求卸载 VoiceDesign 返回 409；生成没有被卸载请求破坏。抽屉里的手动卸载实际完成并显示“尚未载入内存”。
- 手动切换到 Qwen Base 0.6B 约 3.02 秒，再切回 VoiceDesign 约 3.36 秒；每次查询只显示目标 TTS 模型载入，最后保留 VoiceDesign。
- 74 项后端测试和 6 项前端测试通过，覆盖兼容性、模型互斥/取消、批次间保护、图书进度接口和已有图书/流式回归。TypeScript 检查、桌面前端构建、Tauri release 编译及网页生产构建通过；保留既有大包体积提示。
- 最终桌面在 1200×800 窗口复查两栏、侧边抽屉、版本折叠和旧播放器移除。移动端及其他硬件上的真实界面未单独验收。

## 使用边界

VoiceDesign 不会自动复刻原有克隆声音的音色；需要克隆声音时继续选 Qwen3-TTS Base。剩余时间依赖当前会话的实际速度样本，并不承诺固定完成时刻。此轮模型互斥验证覆盖语音生成、图书、预热与模型管理路径；不将其扩展为所有外部调用方的并发保证。
