# 长文本即时试听：实现与实测

日期：2026-10-16。状态：已实现可选测试功能；持续性能验收仍按下文实测判断。

本次交付解决“必须等待全文合成完才能听”的时效性问题。一次提交全文后，Qwen Base 原生流式推理持续产出 PCM，浏览器播放器随生成进度播放。最终完整 WAV、历史记录和版本保存继续使用现有流程。

## 使用

1. 选择 Qwen3-TTS 和已有声音，速度优先可选择 0.6B。
2. 勾选“边生成边听（测试 · CUDA · 默认输出设备）”，等提示“即时朗读已预热”。首次预热包含模型加载、声音提示计算和编译；切换声音或模型后重新预热。
3. 提交长文本。底部显示播放/缓冲状态和已播/已接收的音频时长；历史列表显示生成阶段、已完成段数、已耗时及可用的剩余时间估算。
4. 暂停只暂停试听，生成继续；停止结束试听并请求取消尚未完成的任务。完成后可重播保存文件，生成完成事件不会让试听从头重播。

首版支持 Windows CUDA Qwen Base、原声、系统默认输出设备。默认音频通道正常支持；指定设备路由、音效预设和有声书/故事暂未接入。关闭测试选项继续使用原生成方式。

## 数据口径

首 PCM 指请求提交至第一个音频包到达，不等于实际扬声器首音。播放器初始预留 0.8 秒、断粮后预留 0.3 秒；Web Audio 时钟计数也不等于硬件回环测量。

RTF = 生成耗时 / 音频时长，小于 1 表示平均生成快于播放。仍需观察包间抖动、段落切换和长时间运行，不能凭一个短句宣布实时性能达标。

硬件为 RTX 5070 Ti，安装版使用 PyTorch CUDA 后端。下列 API 测试使用已有声音、固定种子 42、中文、原声，输出归一化后保存；预热耗时单独列出。

| 测试 | 首 PCM | 生成总耗时 | 音频时长 | RTF | 缓冲模拟断粮 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 安装版 API / 0.6B / 200 字 | 0.667 秒 | 34.69 秒 | 40.30 秒 | 0.861 | 0 |
| 安装版 API / 0.6B / 2000 字 | 0.639 秒 | 333.81 秒 | 382.41 秒 | 0.873 | 0 |

该次首次预热耗时 37.03 秒。以上仅单次结果，不是 P50/P95。

2000 字测试前复用已加载模型，额外预热 3.39 秒。输出超过 6 分钟，逐包缓冲模拟没有断粮；这证明本次供给速度有余量，尚不能代替 WebView 后台/扬声器连续播放验收。原定持续 RTF ≤0.75 目标尚未达到。

独立模型实验另测得 0.6B 热态首 PCM 0.605 秒、RTF 0.905；1.7B 未优化流式热态 RTF 约 1.80，独立 codebook 编译后某次热态约 1.03。不同实验的解码窗口/矩阵精度不完全一致，这些结果用于筛选，生产结论以上述安装版 API 为准。未采用额外编译音频解码器：该实验增加冷启动且未观察到持续速度收益。

## 实现

- 首段约 40 字，后续段最多约 160 字，沿用自然标点分段。整个正文无需合成完成才开始输出；每段内部也原生流式产出，而非等整句 WAV 完成。
- Qwen 每 8 codec 帧输出一包，解码窗口 80 帧。单个串行推理 worker 使用有界生产者队列；取消时等待推理线程退出后才允许后续任务进入。
- 服务端临时 PCM 写入磁盘，读者单次最多读取 24000 样本；客户端预排音频保持约 6 秒上限，网络单包最多约 1 秒。暂停/网络变慢不会把整个长文本的声音积压到前端内存。
- PCM 帧带采样率和样本数，独立成功/失败终止帧。断连或没有成功终止帧不会显示“已保存”；服务端支持按样本偏移重新读取，客户端当前将断连显示为试听失败，完整生成可继续。
- 跨文本段预留短尾后再淡化，避免重复播放已发出的尾部。实时试听不等待全篇响度分析；导出的归一化分两遍写独立文件，原始试听 PCM 保持不变。
- 临时 PCM 正常终止后保留一小时；进程异常退出留下的文件尚需后续启动清理，长文本会占用与生成长度相关的临时磁盘空间。
- Qwen 声音提示缓存增加模型尺寸命名空间。1.7B/0.6B embedding 尺寸不同，不能复用同一提示缓存；旧缓存不会被新路径误读。

当前使用 Web Audio 的短 AudioBuffer 定时排播，尚非 AudioWorklet/native PCM sink；严格低延迟、多设备与后台节流验证仍在后续范围。

## 验证与复现

- 后端 32 项回归通过：PCM 提前输出、断连/失败协议、样本偏移读取、跨段拼接、归一化、取消/线程串行、预热不创建历史、默认通道放行、自定义通道拦截、跨模型缓存隔离，以及已有进度/任务/缓存回归。
- 前端 PCM 解析 4 项测试通过，覆盖所有字节分割位置、逐字节输入、多包、非法浮点数、失败与缺失终止帧。
- TypeScript 类型检查、桌面前端构建、Tauri release 编译通过。保留现有代码分包体积警告。
- 网页版生产构建通过；网页版的实际播放本轮未单独验收。
- 实际安装版已确认 CUDA、预热就绪、生成未完成时 WebView 音频正在播放；暂停后后台完成保存且试听位置保持。
- 桌面恢复播放后达到 28s/28s 并显示“朗读完成，音频已保存”，没有自动从头重播。停止另一个排队试听任务后，该任务记录为 `Generation cancelled`、时长 0，2000 字任务保持运行并最终成功。
- 对 200 字保存文件进行了本地 Whisper Base 内容检查：转录包含预期句子顺序及原文重复段，存在同音/用字差异。该检查不等于逐字正确、音色或音质的人工验收。
- 在真实 CUDA 推理产出第一包后取消另一个验收任务：0.834 秒后服务端发出失败终止帧，任务退出活动队列并记录 `Generation cancelled`。该数值包含推理线程退出等待，不是停止按钮至扬声器静音的测量。
