## 回复操作栏调整

参考 DeepTutor 的消息朗读操作，将手动朗读及播放状态迁移到官方 `conversation.chat.assistant-actions` 插槽，紧邻回复的复制按钮。顶部只保留会话自动播报开关。

- 实际 DSH Desktop 已显示每条已完成回复的喇叭按钮，点击历史回复只读取该条的文本。
- 按钮及状态沿喇叭、生成中、停止、暂停/继续切换，状态使用实际 message id 归属，不会出现在其他回复下方。
- 播放期间在对应回复下显示已播放时间，暂停后提供继续与停止；旧回复正在播放时，其操作栏保持可见。
- 回归覆盖历史分页后手动朗读、另一条回复接管播放、自动播报 message id 绑定，以及停止暂停的旧回复后恢复已解锁的音频上下文。
- 本机 Desktop 实际复验：历史回复下启动朗读并暂停，发送新消息后旧回复恢复喇叭；新 AI 回复自动显示“播放中”并推进计时，完整结束后恢复喇叭。暂停状态不会阻止下一条回复自动播放。

## 其余验证范围

发送新消息与切换会话的取消、历史不自动重播、子智能体过滤及重复请求已有自动测试和浏览器夹具覆盖。本机 Desktop 本轮真实任务重点验证自动触发、PCM 播放、暂停恢复、正常结束与停止取消。

本轮没有进行音色/音质的人工主观评价、多窗口并发验收或其他 DSH 版本的完整安装验收。自动播报只对当前可见且获得焦点的会话生效；新会话默认关闭，需要点击会话栏开关。
